## 5. How a lane PR is gated (the recipe that worked)

1. `gh pr diff <n> --stat` — confirm test/docs only (or the isolated branch for a fix). Product files in a test-only lane = reject.
2. Integration files changed vs main, at a **kept plain container** so rows can be dumped after:
   ```
   export DOCKER_HOST=unix:///Users/joshuakay/.colima/default/docker.sock TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock
   CID=$(docker run -d --rm -e POSTGRES_USER=test -e POSTGRES_PASSWORD=test -e POSTGRES_DB=serviceos_test -p 127.0.0.1:0:5432 pgvector/pgvector:pg16 -c max_connections=300)
   PORT=$(docker port $CID 5432 | head -1 | awk -F: '{print $NF}')   # wait for pg_isready
   cd packages/api && RLS_RUNTIME_ROLE=true EXTERNAL_TEST_DB_URL=postgres://test:test@localhost:$PORT/serviceos_test \
     npx vitest run --config vitest.integration.config.ts --reporter=verbose <files>
   docker exec $CID psql -U test -d serviceos_test -P pager=off -c "SELECT …"   # the rows the proof wrote, by tenant
   ```

## 7. Lessons this segment (each cost time)

- **The Mac's disk hit 0 B mid-Playwright** (04:09Z): every tool got `ENOSPC`, two specs died with `exit=1` and no result line, and colima's containerd store threw `input/output error` until the host had room. Recovery: `npm cache clean --force`, `rm -rf ~/.npm/_npx`, Trivy's `~/Library/Caches/java-db`, `uv cache clean` (≈3.6 G), then `colima restart` (fixed the I/O errors and reclaimed ≈12 G from the sparse VM image). Nothing under `~/.claude` or `~/Library/Application Support/Claude` is ever touched.
- **Lanes keep pushing after gates and after merges.** Close a lane PR only when `git diff origin/main...origin/<branch>` is empty; merge only at the gated head (`--match-head-commit`); expect a push between gate and merge and guard for it.
- A "green" grep over a union log must skip the log's own header lines (a header that *mentions* `exit=1` tripped it once).
- zsh expands inline assignments left to right: `PORT=3101 DATABASE_URL=…:$PORT/…` points the app at its own HTTP port ("Connection terminated unexpectedly" on every query). Use a different variable name for the DB port.
- Invoice creation over the API needs `totalCents`, `sortOrder` and `taxable` per line item; the 400 says only "Required" ×3.
