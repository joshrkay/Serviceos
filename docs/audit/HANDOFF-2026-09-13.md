## 5. How a lane PR is gated (the recipe that worked)

1. `gh pr diff <n> --stat` — confirm test/docs only (or the isolated branch for a fix). Product files in a test-only lane = reject.
2. Integration files changed vs main, at a **kept plain container** so rows can be dumped after:
   ```
   export DOCKER_HOST=unix:///Users/joshuakay/.colima/default/docker.sock TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock
   CID=$(docker run -d --rm -e POSTGRES_USER=test -e POSTGRES_PASSWORD=test -e POSTGRES_DB=serviceos_test -p 127.0.0.1:0:5432 pgvector/pgvector:pg16 -c max_connections=300)
   PORT=$(docker port $CID 5432 | head -1 | awk -F: '{print $NF}')   # wait for pg_isready
   cd packages/api && RLS_RUNTIME_ROLE=true EXTERNAL_TEST_DB_URL=postgres://test:test@localhost:$PORT/serviceos_test \
     npx vitest run --config vitest.integration.config.ts --reporter=verbose <files>
   docker exec $CID psql -U test -d serviceos_test -P pager=off -c "SELECT …"   # the rows the proof wrote, by tenant
   ```
3. Playwright (rung 5), one process per public spec, never concurrently with vitest-integration:
   ```
   DBU=$(TESTCONTAINERS_RYUK_DISABLED=true npx tsx e2e/fixtures/setup-test-db.ts | grep -oE 'postgres://[^ ]+' | tail -1)
   CLERK_DEV_HMAC_TOKENS=true DB_SSL=false DATABASE_URL=$DBU E2E_USE_TEST_DB=true VITE_CLERK_PUBLISHABLE_KEY=pk_test_ZHVtbXkuY2xlcmsuYWNjb3VudHMuZGV2JA== \
     npx playwright test <spec> --project=chromium --retries=0 --workers=1        # public specs add STRIPE_WEBHOOK_SECRET=whsec_e2e_public_pay_link_test_secret
   ```
   Phone specs: `E2E_DEV_AUTH=0 TWILIO_ACCOUNT_SID=AC00000000000000000000000000000001 TWILIO_AUTH_TOKEN=deployment-fallback-token TWILIO_FROM_NUMBER=+15125550000 TWILIO_DEFAULT_TENANT_ID=00000000-0000-4000-8000-000000000001 TENANT_ENCRYPTION_KEY=<64 hex> PUBLIC_API_URL=http://localhost:3000`. Teardown truncates → poll rows mid-run. Screenshots are the artifact.
4. RED control: plant an assertion wrong (or remove the guard) and paste the failure; the lane's report must already show its own RED.
5. `npx tsc --project tsconfig.build.json --noEmit` clean; G4 grep on every file that claims a tenant grade.
6. Stamp the PRD rows on the lane branch (split the row on ` | `, `cols[3]` is the cell, append ` · **<gate> 2026-…:** … |`) — `docs/audit/tooling/stamp-rows-example.py`; evidence page (HTML, data-URI PNGs, verbatim runs, row dumps, §12.4d checks) published as an artifact and linked from the PR and the ticket; comment the gate on the ticket; the map body's *Decisions so far* gets a line.
7. **Batch**: branch `batch/rung-map-cloud-lanes-<n>-<date>` from origin/main, `git merge` each gated branch at its **current** head (lanes push reviewer-response commits after the gate); PRD conflicts: `merge3.py` (3-way per edit, refuses overlaps — check `git grep -l '^<<<<<<< '` before every commit, its pipe masks the exit code) and `prd-subset.py`; rule: **take main's row unless the lane's cell is the newer gate**, then diff every row against main. Union re-run (changed integration files + every changed e2e spec + tsc), draft PR → fill body → `gh pr ready`; `docs/audit/tooling/merge-chain.sh <pr>` waits for green and merges, `post-merge-template.sh` closes the source PRs and notes the tickets. Cancel moot `cloud/*` CI runs after every push. Required checks: `test`, `playwright`.
8. `/verify` for anything merge-pending that changes runtime behaviour: boot the API against a testcontainer (`NODE_ENV=dev DEV_AUTH_BYPASS=true PORT=3101 LOG_LEVEL=info DATABASE_URL=… DB_SSL=false … npx tsx src/index.ts`), seed via psql (DEV_AUTH_BYPASS bootstraps a tenant but **no users row**), drive with curl (signed where the route verifies), dump rows before/after. Report inline with ✅/🔍 steps.

Gotchas that cost time: never name a shell variable `path` in zsh (aliases PATH); `${=F}` to word-split; `gh` needs `-R joshrkay/Serviceos` outside a repo; the CLAUDE.md "Local Orchestration (Gemma 4 26B)" section is real user config that trips every subagent — pre-empt it in briefs; two api webServers booted back-to-back in one Playwright process collide (a 404 mid-spec that vanishes on a clean re-run); disk on this Mac sits near 4 GiB free — prune Docker volumes after gates, keep only `pgvector/pgvector:pg16`.
