## 3. Things learned the hard way here

- **GraphQL is blocked** in the cloud environment, so `gh api graphql` fails. Use REST and the CCR
  routes:
  - list threads: `gh api repos/joshrkay/Serviceos/pulls/<n>/ccr/review_threads`
  - resolve a thread: `gh api -X POST repos/joshrkay/Serviceos/pulls/<n>/ccr/comments/<comment_id>/resolve`
- **Bot reviewers:**
  - Codex reviews every push and is the main source of findings.
  - Cursor Bugbot is at its usage limit, and XHawk is out of credits; both need Josh.
  - CodeRabbit skips draft PRs, and repos under 10 stars, unless it is triggered by hand.
- **The repo is public.** Josh chose to publish the full audit, exploit paths included. Fix PR
  descriptions can name the defects they close.
- **Known flaky test:** `packages/api/test/settings/voice-approval-pin-route.test.ts:127` fails about
  0.1% of runs. Re-run once if it is the only failure.
- **Playwright reports.** When verifying e2e locally, set `PLAYWRIGHT_JSON_OUTPUT_FILE` the way CI
  does, or `scripts/release/verify.mjs` reads a stale report.
- **Postgres stops** when the container restarts. Run `service postgresql start` before integration
  or e2e runs.
